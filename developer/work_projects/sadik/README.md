# «Альтаир» — промосайт детского сада

Статичная адаптивная landing page. Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

Весь опубликованный контент взят из переданного WhatsApp-чата. Кнопка формы открывает WhatsApp с предзаполненным сообщением; серверной обработки персональных данных нет.
